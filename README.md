# Snehal A. Kanase — Bioinformatics Portfolio

A responsive, static HTML/CSS/JavaScript portfolio prepared for GitHub Pages.

## Files
- `index.html` — page content and metadata
- `style.css` — responsive layout, colors, typography, and project visuals
- `script.js` — mobile menu and current footer year

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL@example.com` and replace it with your professional email address.
3. Find `YOUR_LINKEDIN_USERNAME` and replace it with the username from your LinkedIn profile URL.
4. Review every project description and tool list. Keep only items you can confidently explain in an interview.
5. If you want to add a CV, upload a PDF you are comfortable making public and add a link to it. Do not upload confidential data or unpublished institutional material without permission.
6. Review employment/institutional policies before advertising external consulting services.

## Publish with GitHub Pages (free)
1. Sign in at https://github.com/.
2. Create a **public** repository named `YOUR-GITHUB-USERNAME.github.io` (replace with your actual GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the deployment to complete. Your site address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

GitHub Pages websites are public. Do not commit passwords, API keys, patient information, confidential research files, or anything you do not want public. It can take several minutes for a new deployment to appear.

Official guide: https://docs.github.com/en/pages/quickstart
